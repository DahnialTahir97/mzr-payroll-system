MZR PAYROLL - PANDUAN DEPLOY VERCEL
====================================

SEBELUM DEPLOY
1. Pastikan database MySQL telah diwujudkan di hosting database (contohnya Railway).
2. Export database MZR sedia ada daripada phpMyAdmin/XAMPP sebagai backup SQL.
3. Import backup tersebut ke database hosting. Pastikan jadual users, employees,
   attendance, salary_components dan payroll serta semua column aplikasi tersedia.
4. Jika belum pernah dibuat, jalankan MIGRATION_LOGIN_ROLE.sql dan
   MIGRATION_MANAGER_APPROVAL.sql sekali sahaja selepas backup.
5. Jangan upload fail SQL yang mengandungi data pekerja sebenar ke GitHub.

DEPLOY VERCEL
1. Buka https://vercel.com/dashboard.
2. Pilih Add New > Project.
3. Import repository DahnialTahir97/mzr-payroll-system.
4. Framework Preset: Container. Jika sudah auto-detect Container, kekalkan.
5. Root Directory: ./ (root repository).
6. Tambah Environment Variables untuk Production:
   DB_HOST = public MySQL hostname
   DB_PORT = public MySQL TCP port
   DB_NAME = database name
   DB_USER = database username
   DB_PASS = database password
7. Klik Deploy. Jika project telah diimport, buat Redeploy selepas ubah env vars.
8. Buka https://DOMAIN-ANDA/health.php.
   Berjaya: status=ok dan database=connected.
   Gagal: semak environment variables dan akses rangkaian database.

SESI LOGIN
Aplikasi menggunakan table mzr_app_sessions di MySQL untuk menyimpan sesi login
merentas container Vercel. Table ini diwujudkan secara automatik apabila aplikasi
menerima request pertama. User database perlu ada kebenaran CREATE, SELECT,
INSERT, UPDATE dan DELETE.

UJIAN WAJIB SEBELUM GUNA
- Admin: login, tambah/edit/padam pekerja, rekod kehadiran, komponen gaji,
  jana payroll, edit payroll, laporan dan cetak slip.
- Manager: login, semak payroll, bonus (jika digunakan), sahkan/tolak slip.
- Employee: login, check-in/check-out, hanya lihat slip sendiri yang approved.
- Uji logout dan login semula di telefon serta laptop.
- Pastikan setiap role tidak boleh membuka URL role lain.

PENTING - KETEPATAN PAYROLL
Kod semasa masih menggunakan anggaran peratusan untuk PERKESO/SIP dan PCB=0.
Jangan gunakan jumlah ini untuk bayaran gaji sebenar atau pemfailan statutori
sehingga jadual rasmi KWSP/PERKESO/SIP dan formula PCB telah dimasukkan serta
disahkan oleh pihak payroll.

JANGAN KONGSI
Jangan kongsi DB_PASS, password akaun, token atau maklumat pekerja melalui chat
atau commit ke GitHub.
