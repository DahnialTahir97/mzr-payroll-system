MZR FOOD SERVICES - PATCH KWSP + PERKESO + SIP/EIS (ANGGARAN)

1. BACKUP folder C:\xampp\htdocs\mzr_payroll_system dahulu.
2. Extract ZIP ini.
3. Copy payroll.php dan contribution_calculator.php ke folder projek.
4. Replace fail lama.
5. Buka http://localhost/mzr_payroll_system/payroll.php
6. Jana semula payroll untuk bulan yang diperlukan.
7. Semak payslip.

Kiraan dalam patch:
- KWSP pekerja: 11% x (gaji asas + elaun).
- PERKESO pekerja: 0.15% x upah (maksimum asas kiraan RM6,000). Kadar ini
  hanya anggaran yang menghasilkan RM7.50 bagi upah RM5,000 seperti contoh
  yang diberikan; ia BUKAN jadual rasmi PERKESO.
- SIP/EIS pekerja: 0.2% x upah, maksimum asas RM6,000.
- SIP/EIS majikan: 0.2% x upah, maksimum asas RM6,000.
- PERKESO majikan: belum dikira kerana kadar/kategori tidak dinyatakan dalam
  arahan yang diberi.
- PCB: belum dikira.

PENTING: Ini DRAFT untuk ujian sistem sahaja. Kadar PERKESO 0.15% tidak boleh
 dianggap kadar statutory rasmi. Semak jadual rasmi PERKESO sebelum guna untuk
 pembayaran gaji sebenar. Slip kekal DRAFT.
